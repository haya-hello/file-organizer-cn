# 演示材料

`demo-downloads/` 是完全虚构的模拟下载目录，用于验证和截图，不包含真实用户文件。

生成默认隐私报告：

```powershell
python "..\file-organizer-cn\scripts\file_organizer.py" report ".\demo-downloads" --output ".\file-organizer-preview.html"
```

仓库中的 `file-organizer-preview.html` 和 `file-organizer-preview.png` 均由上述模拟材料生成。报告默认不包含文件名或本机绝对路径。
